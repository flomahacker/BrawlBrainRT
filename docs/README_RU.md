# Brawl Dodge AI — M1: инструкция на русском

## Что уже есть

M1 — это только захват экрана и debug-визуализация. Приложение не двигает персонажа и не отправляет игровые касания.

По умолчанию:

- захват примерно 640×288;
- берётся только самый новый кадр;
- обработка идёт в native C++;
- есть overlay поверх игры;
- есть thermal-safe режим;
- touch injection = OFF.

## Установка

1. Установи APK из GitHub Actions artifact.
2. Запусти Brawl Dodge AI M1.
3. Разреши Поверх других приложений.
4. Нажми запуск захвата.
5. Подтверди системное разрешение записи/захвата экрана.
6. Перейди в Training Cave.

На Xiaomi 12X для стабильности рекомендуется отключить экономию батареи для приложения и разрешить автозапуск.

## Что смотреть

Overlay показывает:

- зелёную рамку — предполагаемый игрок;
- красную — враг/кандидат врага;
- оранжевую — кандидат зоны;
- жёлто-оранжевую маленькую рамку — кандидат снаряда;
- FPS pipeline;
- возраст захваченного кадра;
- время native CV;
- thermal status.

## Ограничения M1

M1 не пытается знать конкретного brawler, тип снаряда или геометрию карты. Цветовые пороги пока общие.

Стены, кусты, вода, точный тип атаки и Kalman tracking появятся в следующих этапах. На этом этапе важно проверить сам pipeline MediaProjection → ImageReader → C++ CV → overlay.

## Как тестировать

Открой Training Cave, запускай debug overlay и посмотри:

- находится ли твой brawler рядом с зелёной рамкой;
- появляются ли красные рамки на врагах;
- замечаются ли быстрые красные снаряды;
- не начинает ли overlay заметно тормозить игру;
- остаётся ли интерфейс стабильным 10–15 минут.

Не включай никакое управление: в M1 его нет.
