# Brawl Dodge AI

Готовая единая Android-версия для Xiaomi 12X / Snapdragon 870.

После запуска приложение:

- сразу показывает HUD поверх других приложений;
- получает экран через MediaProjection;
- анализирует свежие кадры без накопления старых кадров;
- ищет игрока, красные угрозы и оранжевые зоны;
- считает уровень опасности;
- показывает направление опасности на экране;
- автоматически снижает частоту анализа при перегреве.

### Запуск

1. Установи APK.
2. Разреши приложению "Поверх других приложений".
3. Нажми "2. Запустить Brawl Dodge AI".
4. Разреши системный захват экрана.
5. Открой Brawl Stars и зайди в Training Cave или Friendly Battle.

Управление игрой приложение не отправляет.

### Xiaomi / HyperOS

Для длительного теста убери жёсткие ограничения батареи для приложения и разреши автозапуск/работу в фоне.

### Важно

Распознавание сделано полностью локально и без скачивания моделей при установке. Это лёгкий vision-baseline, а не идеальный универсальный классификатор всех бойцов и снарядов.
